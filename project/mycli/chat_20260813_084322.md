**函数：计算两个数字的和**

```python
def calculate_sum(num1, num2):
    """
    计算两个数字的和

    Args:
        num1 (float): 第一个数字
        num2 (float): 第二个数字

    Returns:
        float: 两个数字的和
    """
    return num1 + num2
```

**使用示例:**

```python
print(calculate_sum(3, 5))  # 输出: 8
```

**函数：判断一个数字是否是质数**

```python
def is_prime(num):
    """
    判断一个数字是否是质数

    Args:
        num (int): 要判断的数字

    Returns:
        bool: True 如果数字是质数,False 否则
    """
    if num <= 1:
        return False
    for i in range(2, int(num ** 0.5) + 1):
        if num % i == 0:
            return False
    return True
```

**使用示例:**

```python
print(is_prime(7))  # 输出: True
print(is_prime(8))  # 输出: False
```

**函数：交换两个变量的值**

```python
def swap_values(a, b):
    """
    交换两个变量的值

    Args:
        a (any): 第一个变量
        b (any): 第二个变量

    Returns:
        tuple: 两个变量的值
    """
    return b, a
```

**使用示例:**

```python
a = 5
b = 10
a, b = swap_values(a, b)
print(a)  # 输出: 10
print(b)  # 输出: 5
```

**函数：计算列表中的最大值**

```python
def find_max(lst):
    """
    计算列表中的最大值

    Args:
        lst (list): 要查找最大值的列表

    Returns:
        any: 列表中的最大值
    """
    return max(lst)
```

**使用示例:**

```python
numbers = [1, 2, 3, 4, 5]
print(find_max(numbers))  # 输出: 5
```

**函数：判断一个字符串是否是回文**

```python
def is_palindrome(s):
    """
    判断一个字符串是否是回文

    Args:
        s (str): 要判断的字符串

    Returns:
        bool: True 如果字符串是回文,False 否则
    """
    return s == s[::-1]
```

**使用示例:**

```python
print(is_palindrome("radar"))  # 输出: True
print(is_palindrome("hello"))  # 输出: False
```

**类：学生信息管理**

```python
class Student:
    """
    学生信息管理类

    Attributes:
        name (str): 学生姓名
        age (int): 学生年龄
        score (float): 学生成绩
    """

    def __init__(self, name, age, score):
        """
        初始化学生信息

        Args:
            name (str): 学生姓名
            age (int): 学生年龄
            score (float): 学生成绩
        """
        self.name = name
        self.age = age
        self.score = score

    def display_info(self):
        """
        显示学生信息
        """
        print(f"姓名:{self.name}")
        print(f"年龄:{self.age}")
        print(f"成绩:{self.score}")

    def update_score(self, new_score):
        """
        更新学生成绩

        Args:
            new_score (float): 新的成绩
        """
        self.score = new_score

    def __str__(self):
        """
        返回学生信息的字符串表示
        """
        return f"{self.name}({self.age}) - {self.score}"
```

**使用示例:**

```python
# 创建学生对象
student = Student("John", 20, 85.5)

# 显示学生信息
student.display_info()

# 更新学生成绩
student.update_score(90.0)

# 显示更新后的学生信息
student.display_info()

# 使用 __str__ 方法打印学生信息
print(student)
```

**类：银行账户管理**

```python
class BankAccount:
    """
    银行账户管理类

    Attributes:
        account_number (str): 银行账户号
        balance (float): 银行账户余额
    """

    def __init__(self, account_number, balance):
        """
        初始化银行账户信息

        Args:
            account_number (str): 银行账户号
            balance (float): 银行账户余额
        """
        self.account_number = account_number
        self.balance = balance

    def deposit(self, amount):
        """
        存入金额

        Args:
            amount (float): 存入金额
        """
        self.balance += amount

    def withdraw(self, amount):
        """
        取出金额

        Args:
            amount (float): 取出金额
        """
        if amount > self.balance:
            print("取出金额超过账户余额!")
        else:
            self.balance -= amount

    def display_info(self):
        """
        显示银行账户信息
        """
        print(f"账户号:{self.account_number}")
        print(f"余额:{self.balance}")
```

**使用示例:**

```python
# 创建银行账户对象
account = BankAccount("123456789", 1000.0)

# 存入金额
account.deposit(500.0)

# 取出金额
account.withdraw(200.0)

# 显示银行账户信息
account.display_info()
```
