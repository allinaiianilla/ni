### 计算器函数
#### 计算器函数功能
计算器函数可以接收用户输入的计算内容,并返回计算结果。

#### 计算器函数实现
```python
def calculator(expression):
    """
    计算器函数,计算用户输入的表达式。

    Args:
        expression (str): 用户输入的计算内容。

    Returns:
        float: 计算结果。
    """
    try:
        # 使用 eval 函数计算表达式
        result = eval(expression)
        return result
    except ZeroDivisionError:
        # 如果表达式中包含除以零的操作,返回错误信息
        return "Error: 除以零"
    except Exception as e:
        # 如果表达式中包含非法字符,返回错误信息
        return f"Error: {str(e)}"


# 测试函数
def main():
    expression = input("请输入计算内容: ")
    result = calculator(expression)
    print(f"结果: {result}")


if __name__ == "__main__":
    main()
```

#### 使用说明
1. 在终端中运行程序。
2. 输入计算内容,例如 `2+2` 或 `3*4`。
3. 程序会输出计算结果。

#### 注意事项
* 使用 `eval` 函数计算表达式可能存在安全风险,因为它可以执行任意 Python 代码。
* 在生产环境中,应使用安全的计算库,例如 `numexpr` 或 `asteval`。

```python
import numexpr as ne
import pyperclip

def calculator(expression):
    """
    计算器函数,计算用户输入的表达式。

    Args:
        expression (str): 用户输入的计算内容。

    Returns:
        float: 计算结果。
    """
    try:
        # 使用 numexpr 计算表达式
        result = ne.evaluate(expression)
        return result
    except ZeroDivisionError:
        # 如果表达式中包含除以零的操作,返回错误信息
        return "Error: 除以零"
    except Exception as e:
        # 如果表达式中包含非法字符,返回错误信息
        return f"Error: {str(e)}"


def main():
    expression = input("请输入计算内容: ")
    result = calculator(expression)
    print(f"结果: {result}")
    
    # 将结果复制到剪切板
    pyperclip.copy(str(result))
    print("结果已复制到剪切板,可以直接粘贴使用")


if __name__ == "__main__":
    main()
```
