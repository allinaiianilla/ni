def calculate(num1, num2, operator):
    """
    计算器函数
    """
    if operator == '+':
        return num1 + num2
    elif operator == '-':
        return num1 - num2
    elif operator == '*':
        return num1 * num2
    elif operator == '/':
        if num2 != 0:
            return num1 / num2
        else:
            return "错误：除数不能为零"
    else:
        return "错误：操作符不支持"

def main():
    print("计算器")
    print("1. 加法")
    print("2. 减法")
    print("3. 乘法")
    print("4. 除法")
    
    choice = input("请选择一个选项（1/2/3/4）：")
    
    if choice in ['1', '2', '3', '4']:
        num1 = float(input("请输入第一个数字："))
        num2 = float(input("请输入第二个数字："))
        
        if choice == '1':
            print("结果：", calculate(num1, num2, '+'))
        elif choice == '2':
            print("结果：", calculate(num1, num2, '-'))
        elif choice == '3':
            print("结果：", calculate(num1, num2, '*'))
        elif choice == '4':
            print("结果：", calculate(num1, num2, '/'))
    else:
        print("错误：操作符不支持")

    main()

```python
def calculate_formula(formula):
    """
    计算器函数
    """
    try:
        return eval(formula)
    except Exception as e:
        return "错误：" + str(e)

def main():
    print("计算器")
    formula = input("请输入计算公式（例如 2+2，3*4，10/2）：")
    
    try:
        result = calculate_formula(formula)
        print("结果：", result)
    except Exception as e:
        print("错误：", e)

if __name__ == "__main__":
    main()
```

这个代码定义了一个 `calculate_formula` 函数来计算用户输入的计算公式。`main` 函数是程序的主入口，用户可以输入计算公式并得到结果。

但是，请注意 `eval` 函数可能存在安全风险，因为它可以执行任意 Python 代码。例如，如果用户输入 `__import__('os').system('rm -rf *')`，程序可能会被删除。

如果你需要一个安全的计算器函数，可以使用一个第三方库如 `numexpr` 或 `asteval`。这些库提供了一个安全的计算器函数，可以计算表达式而不执行任意 Python 代码。

例如，你可以使用 `numexpr` 库来计算表达式：

```python
import numexpr as ne

def calculate_formula(formula):
    """
    计算器函数
    """

        return ne.evaluate(formula)
    except Exception as e:
        return "错误：" + str(e)

def main():
    print("计算器")
    formula = input("请输入计算公式（例如 2+2，3*4，10/2）：")

        print("结果：", result)
    except Exception as e:
        print("错误：", e)

if __name__ == "__main__":
    main()
```

这个代码使用 `numexpr` 库来计算用户输入的计算公式。它提供了一个安全的计算器函数，可以计算表达式而不执行任意 Python 代码。
