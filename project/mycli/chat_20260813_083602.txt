以下是一个Python函数，用于计算两个数字的最大公约数（GCD）：

```python
def gcd(a, b):
    while b != 0:
        a, b = b, a % b
    return a

# 测试函数
print(gcd(48, 18))  # 输出 6
```

这个函数使用欧几里得算法（Euclidean algorithm）来计算两个数字的GCD。它通过不断取余数，直到余数为0时，返回的余数就是GCD。
