**简单的Python函数**

以下是一个简单的Python函数，用于计算两个数的最大公约数（GCD）。

```python
def gcd(a, b):
    """
    计算两个数的最大公约数（GCD）。

    Args:
        a (int): 第一个数。
        b (int): 第二个数。

    Returns:
        int: 两个数的最大公约数。
    """
    while b:
        a, b = b, a % b
    return a

# 示例使用
print(gcd(48, 18))  # 输出：6
```

在这个函数中，我们使用欧几里得算法来计算两个数的GCD。该算法通过反复取余数来找到两个数的最大公约数。
