## 基础章节总结

1. 知道了什么是程序, 就是一系列指令,计算机根据指令进行工作
2. java程序有java的规则
3. java程序的文件后缀是 .java
4. java程序的注释前面是 // 这是注释,不会当成指令执行
5. java程序的语句后面是 ;
6. java程序的变量 要求比较严格, `类型 名称=值;`
7. java程序的执行 先从main方法开始
8. java程序的基本格式:
```java
public class Hello{
    public static void main(String[] args){
        System.out.println("hello"); // 打印hello
    }
}
```
9. java程序打印函数是: `System.out.println()`
10. java程序的输入是Scanner+System.in
11. java程序的数据类型 int String double
12. java程序的数据类型转换: int->String, String->int
13. java程序有各种运算与计算: 加减乘除,大小比较,逻辑关系
14. java程序中有条件控制语句, 根据需要执行不同的命令 if else
